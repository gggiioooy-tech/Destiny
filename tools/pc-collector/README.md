# PC 연결 시험

## Windows 최초 설치와 사이트 자동 실행

사이트의 `15month-pc-connect.zip`을 풀고 `install.cmd`를 실행한다. 현재 사용자 폴더에 연결 프로그램과 SHA-256을 고정 검증한 공식 Node.js v24.16.0 실행 파일을 설치한다. 관리자 권한과 전역 실행 정책 변경은 필요 없다. `month15-collector://start`를 현재 사용자에게 등록하며 URL의 인자는 받지 않는다. 사이트 버튼에서 브라우저의 프로그램 열기를 허용하면 실행된다. 설치 직후 다시 연결하면 된다.

이 설치 파일에는 캡처, 계정 정보, 실험용 해석 설정이나 게임 스키마가 포함되지 않는다. 다른 PC에서는 연결 프로그램만 준비되며, 게임 수집 설정과 Npcap 설치는 별도다. 독립적인 실시간 수집기 설치 패키지가 아니다. `uninstall.ps1`은 URL 연결만 해제하며 수집 자료는 지우지 않는다.

현재 단계는 준비된 Npcap 수신 자료 → 로컬 해석 → 사이트 로그인 세션으로 기록 저장이다.
사이트 로그인 정보는 로컬 프로그램으로 전달하지 않는다. 연결 창의 출처·창 식별·일회성 난수를 검사하며, 로컬 서버는 127.0.0.1에만 바인딩한다.

`node tools/pc-collector/server.mjs`와 `node tools/pc-collector/watch.mjs` 실행 후 15월사이트 길드전의 ‘PC 수집기 연결’을 누른다. 로컬 상태 폴더는 `%LOCALAPPDATA%/15month-collector`이며 `COLLECTOR_STATE_DIR`로 변경할 수 있다. `config.json`과 캡처/스키마/영웅 식별 자료는 로컬 전용이다.

현재 watch는 준비된 한 TCP 연결의 pcap을 읽는다. 자동 프로세스/어댑터 재탐색, 게임 재접속 복구, 정식 설치 프로그램은 아직 없다. 프레임/연결이 불완전하면 추정하지 않고 보류한다. 본문 해석 설정은 기존 로컬 SeRab 실험에서 확인한 값에 의존하므로 독립 수집기 완성으로 간주하지 않는다.

10월 16일 확인: 공격/방어 각각 첫 페이지 50건 수신. 전체 150건 수집 완료가 아니다. 사용자가 확인한 상대는 10월 14일 MadDay, 10월 12일 화산파. `MSimplePlayer.GuildSimpleInfo`는 개별 유저 정보이므로 매칭 상대 식별에 사용하지 않는다. 사용자가 확인한 10월 14~15일 기록은 14일 MadDay전, 12~13일 기록은 12일 화산파전으로 로컬 config.periods에 지정했다. 새 날짜는 추정하지 않고 보류한다. 연결한 사이트의 로그인 세션으로 submit RPC를 호출하며, sourceGuild와 보호된 회원 메모가 다르면 서버에서도 거부한다. 재전송은 추가 복사하지 않는다.

영웅·펫 한글 이름은 아직 검증되지 않아 ID를 보존하고 번호로 표시한다. 원본 ReplayUrl·계정 UID·패킷을 서버로 보내지 않는다. 시작 예약 스킬은 별도 보강이 남아 있다. 게임 자동 재연결과 독립적인 이름/프로토콜 매핑은 완료되지 않았다.
