# 15월 PC 수집기 설치

1. 배포 ZIP을 새 폴더에 풀고 이거누르면설치됨.cmd 실행.
2. Node.js 24.16.0, Python 3.14.8 임베디드 런타임, protobuf 7.36.2를 공식 배포처에서 SHA-256 검증 후 사용자 폴더에 설치.
3. Npcap이 없으면 서명 검증한 공식 설치 프로그램을 실행. Windows 관리자 승인과 Npcap 설치 화면은 사용자가 완료해야 함.
4. 게임 실행 → 승인된 계정으로 사이트 로그인 → PC 수집기 연결.
5. 보호된 회원 메모에서 소속 길드를 확인하고 승인된 계정에만 제공되는 해석 설정을 받아 로컬 config.json 생성. 설치된 게임 실행 파일에서 스키마를 추출. 개발 PC 경로·캡처·로그인 정보는 배포하지 않음.
6. 수집 시작 후 게임에서 길드전 홈과 전장/기록 목록을 열면 수신·해석·로그인 세션으로 저장. 한 세션 최대 10분, 연결 변경 시 남은 시간 동안 재탐색.

새 매칭은 실제 길드전 홈 응답의 전투 모드(검증된 ModeType 4), 시작/종료 시각, 상대 GuildID와 GuildName, 시즌과 라운드로 구분. 전투 모드가 아니거나 홈 응답이 없으면 추정하지 않고 보류. 상대 방어팀 캐시는 매칭과 배치 명단별로 분리.

게임 프로세스가 경로를 공개하지 않으면 이 PC의 ProgramFiles 아래 Netmarble 기본 설치 경로를 사용. 다른 위치의 게임은 실행 프로세스에서 경로를 읽을 수 있어야 함. 게임 업데이트로 프로토콜이 바뀌면 추가 호환성 검증이 필요함.

본 버전은 게임 요청이나 화면 조작을 대신하지 않음. 승인된 사이트 계정과 인터넷이 첫 자동 설정 및 사이트 저장에 필요. Npcap은 공식 다운로드 방식이며 설치본에 재배포하지 않음. 해석 프로필은 기존 실험에서 검증한 값으로, 게임 버전별 독립 검증이 모두 끝났다는 의미는 아님.

## 검증
구문/빌드, 별도 빈 상태 폴더에서 전용 Python+protobuf만으로 스키마 추출, 승인되지 않은 계정 설정 접근 거부, ZIP의 개인 설정/캡처 제외를 확인한다. 실제 다른 PC의 드라이버 설치와 게임 통신은 해당 PC에서 최종 확인이 필요하다.


## 자동 업데이트

PC 자동 실행은 등록하지 않습니다. 사용자가 연결 프로그램을 실행하면 업데이트를 백그라운드에서 확인합니다. 수집 중에는 적용을 보류하고, SHA-256 검증과 허용된 파일 목록 확인 후 프로그램 코드만 갱신합니다. 개인 config.json, 수집 기록, Python·Node·Npcap은 덮어쓰지 않습니다. 실패하면 기존 파일을 복구합니다. 이 기능이 없는 구버전은 최초 한 번 재설치해야 합니다.

배포 시 release.json 버전을 올리고 `python scripts/package-collector.py`를 실행해 설치 ZIP, 코드 전용 업데이트 ZIP, 배포 매니페스트를 함께 갱신하세요. 실행 환경 자체 변경은 별도 재설치가 필요합니다. 테스트는 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify-collector-update.ps1`입니다.
