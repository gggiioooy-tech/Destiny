# PC 연결 시험

현재 단계는 Npcap 수신 → 로컬 해석 → 사이트 연결 상태 표시까지다.
사이트 로그인 정보는 로컬 프로그램으로 전달하지 않는다. 연결 창의 출처·창 식별·일회성 난수를 검사하며, 로컬 서버는 127.0.0.1에만 바인딩한다.

`node tools/pc-collector/server.mjs`와 `node tools/pc-collector/watch.mjs` 실행 후 15월사이트 길드전의 ‘PC 수집기 연결’을 누른다. 로컬 상태 폴더는 `%LOCALAPPDATA%/15month-collector`이며 `COLLECTOR_STATE_DIR`로 변경할 수 있다. `config.json`과 캡처/스키마/영웅 식별 자료는 로컬 전용이다.

현재 watch는 준비된 한 TCP 연결의 pcap을 읽는다. 자동 프로세스/어댑터 재탐색, 게임 재접속 복구, 정식 설치 프로그램은 아직 없다. 프레임/연결이 불완전하면 추정하지 않고 보류한다. 본문 해석 설정은 기존 로컬 SeRab 실험에서 확인한 값에 의존하므로 독립 수집기 완성으로 간주하지 않는다.

10월 16일 확인: 공격/방어 각각 첫 페이지 50건 수신. 전체 150건 수집 완료가 아니다. 사용자가 확인한 상대는 10월 14일 MadDay, 10월 12일 화산파. `MSimplePlayer.GuildSimpleInfo`는 개별 유저 정보이므로 매칭 상대 식별에 사용하지 않는다. 정확한 전쟁 회차 정보와 영웅·펫 이름 매핑 검증 후 기존 submit RPC 연결을 진행한다. 이 단계는 실제 전투 업로드를 수행하지 않는다.
