# 패시브 보완과 수집 복구 · 2026-10-22

## 자료
사용자가 허용한 두 길드전 기록 599건(공격300·방어299)을 로컬 tmp/passive-completion에 보관했다. 시작 스탯을 포함한 빨간약 분석599건, 제한된 PC 수신 파일과 관측된 이력 프레임도 로컬에만 있다. 새 원본 리플레이는 영웅 구성을 우선해 40개만 내려받았으며 41종 영웅을 포함한다. 계정·전투 식별자·서버 경로·개인 스탯은 공개 파일에 옮기지 않는다. 수집/분석 프로세스는 자료 저장 후 종료했다.

- 역할 지원의 3인 전투 2명 조건, 체력 조건과 발동 횟수 제한, 부활 후 상태/게이지/중첩, 사망 반응, 기본 공격/스킬 주기 발동, 새로 생긴 버프의 턴 처리 보완.

## 수집기 수정
기존 빨간약 시작은 watch --red만 실행하여 PC 수신이 꺼진 상태에서 재접속해도 새 데이터를 못 받았다. 권한4 검사를 통과한 빨간약 시작에서 필요한 PC 수신을 함께 실행한다. 자신이 시작한 수신과 분석은 종료 때 둘 다 중단하고, 둘 중 하나의 종료가 실패해도 다른 종료를 시도한다. 오류 문구를 TCP 시작 대기/수집 파일 대기/해석 실패로 분리하며 새 수신 파일로 바뀌면 예전 해석 오류를 지운다. 버전2026.10.22.1, 모드별 권한/종료 검증 통과.
