# 사용자 제공 탄성·파쇄 규칙

2026-10-21 추가 설명을 구현 기준으로 사용했다. 퍼센트 입력은 200%=200으로 받는다.

- 치명 배율은 max(1, (치명피해 − 탄성)/100). 일반 공격에는 적용하지 않는다.
- 막기와 추가 막기 버프의 합을 0~100으로 제한한 다음 막기 디버프 및 공격자의 파쇄를 차감하고 0~100으로 제한한다.
- 치명 확률은 치명타 확률에서 유효 막기를 차감하고 0~100으로 제한한다. 반대로 유효 막기가 더 크면 그 차이를 막기 확률로 사용한다. 나머지는 일반 공격이다. 이는 현재 사용자가 제시한 예제를 일반화한 실험 모델이다.
- 200/50 → 치명 배율 1.5, 150/60 → 1, 치확100/막기80/파쇄30 → 치명 확률 .5를 테스트했다.
- 막기 피해 감소량은 확률과 별개 입력이며 기본 50%는 조정 가능한 실험 설정이다.
