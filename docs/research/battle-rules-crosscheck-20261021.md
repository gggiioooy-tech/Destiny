# 성장 기준·전투 규칙 교차 조사

확인일 2026-10-21. 영웅 자료의 공통 기준은 사용자가 지정한 **6초월·5강·풀스킬 강화**다. 장착 장비가 다른 실제 수집 스탯을 동일한 값으로 환산한다는 뜻은 아니다. 지정된 각성 영웅은 기존 각성 기준을 유지한다. 현재 엔진 지원 영웅은 여전히 연희·쥬리·각성 윤건이며 61명 자료 확보와 61명 실행 구현은 구분한다.

## 인터넷 3곳 대조

1. [나무위키 시스템 문서의 공개 미러](https://www.namu.moe/w/세븐나이츠%20리버스/시스템): 팀 속공 합으로 첫 스킬 팀 결정, 양 팀 스킬 교대, 스킬 사이 기본 공격 2회, 기본 공격 차례에 개인 턴 감소, 제어로 행동 못 해도 턴 소모, 스킬·협공은 개인 턴을 소모하지 않는다고 설명한다.
2. [신 기자의 직접 플레이 리뷰](https://www.1conomynews.co.kr/news/articleView.html?idxno=41082): 팀 속공 총합으로 선스킬 팀 결정, 기본 공격 2회마다 팀을 바꿔 스킬을 쓴다고 설명한다. 웹 도구가 403을 반환해 공개 HTML을 직접 읽어 본문을 확인했다.
3. [불의 원소 던전 직접 클리어 공략](https://gall.dcinside.com/mgallery/board/view/?id=sevennightsrebirth&no=58542): 스킬 사이 평타 2회, 아군 스킬에서 다음 아군 스킬까지 총 평타 4회라는 실전 운용을 설명한다. 행동 제어로 상대 스킬 기회를 막는 사례도 제시한다.

동일 위키의 서로 다른 미러를 독립된 출처로 세지 않았다. 2025년 공략·리뷰이므로 현재 패치의 모든 세부 처리까지 증명하지 않는다. [LD플레이어 사전 소개](https://kr.ldplayer.net/blog/seven-knights-rebirth-vs-original-gameplay-comparison.html)도 읽었으나 출시 전 자료라 확인 수를 부풀리는 근거로 사용하지 않았다.

| 항목 | 교차 조사 결과 | 구현 상태 |
|---|---|---|
| 기본 구조: 스킬 → 기본 공격 2회 → 반대 팀 스킬 | 3곳 일치 | 기존 임시 스케줄 교체 필요 |
| 팀 속공 합에 따른 첫 스킬 | 위키·플레이 리뷰 일치, 로컬 전투 첫 스킬과 부합 | 기존 개인 속공 정렬만으로는 부족 |
| 개인 속공 순서의 기본 공격 | 위키 및 로컬 전투 초반과 부합 | 기본 공격과 스킬을 별도 큐로 분리 필요 |
| 스킬이 개인 지속 턴을 줄이지 않음 | 위키 설명, 로컬 기록의 스킬 사이 동일 TotalTurn과 부합 | 현재 모든 행동에서 감소시키는 임시 구현 수정 필요 |
| 동일 속공의 세부 동률 처리 | 위키에 자리 번호·랜덤 설명, 3곳 모두에서 확인하지는 못함 | 미확정 |
| 쿨타임 시간축·자동 스킬 가중치·각성 삽입 순서 | 자료가 부족함 | 미확정, 임의 공식으로 완료 처리하지 않음 |

로컬 비교는 이미 허용받아 저장된 2026-10-19 전투만 사용했다. 초반 관측은 연희 2스(턴0) → 연희 평타(턴1) → 쥬리 평타(턴2) → 시노부 2스(턴2) 순서다. 이는 기존 기록을 비교한 것이며 추가 게임/리플레이 서버 요청은 없다. 추가타·협공·연속 발동을 일반 스킬 차례로 잘못 세면 안 된다.

## 효과 적중·저항

사용자 규칙 및 [사용자가 지정한 설명글](https://gall.dcinside.com/mgallery/board/view/?id=sevennightsrebirth&no=775543)을 대조했다.

```text
잔여 저항 = clamp(효과 저항 − 효과 적중, 0, 100)
최종 적용 확률 = 스킬 자체 발동 확률 × (1 − 잔여 저항 / 100)
```

예: 기본 50%, 저항100·적중30 → 최종15%. 저항100·적중100 → 최종50%. 적중이 저항보다 높아져도 기본 발동 확률을 넘지 않는다. 음수 저항을 추가 발동 보너스로 바꾸지 않는다. 면역은 확률 이외의 별도 조건이다.

설명글은 자체 확률 → 저항 순서로 기술하고, 사용자 설명은 반대 순서로 기술한다. 독립적인 두 판정의 최종 확률은 같지만 실제 엔진의 난수 소모 순서까지 검증했다는 뜻은 아니다. 현재 구현은 사용자 설명대로 저항 → 자체 확률의 두 번 판정이다.

[아카라이브 링크1](https://arca.live/b/sevennightsrebirth/153565297), [링크2](https://arca.live/b/sevennightsrebirth/142903470)는 접근 오류/403으로 본문을 읽지 못했다. 읽은 출처로 계산하지 않았다.

## 펫·장비 자료

[펫 문서](https://www.namu.moe/w/세븐나이츠%20리버스/펫)에서 44개 펫 구간, [장비 문서](https://www.namu.moe/w/세븐나이츠%20리버스/장비)에서 9개 세트와 32개 장신구 구간을 확보했다. 성장 수치와 특수 효과 설명을 로컬 JSON으로 구분했다. 색인과 출처·스냅샷 해시는 `pet-equipment-catalog.json`에 기록했다. 확보와 엔진 구현 완료를 혼동하지 않는다.

장비 자료에서는 부활·불사·권능과 영웅 패시브의 중복 제한, 세트의 상시 스탯과 조건부 효과, 반지 성급별 효과를 구분한다. 최종 수집 스탯을 쓸 때 장비·펫 상시 증가를 다시 더하지 않는다. 원본 수치를 쓰는 빌드 계산기와 별도 처리해야 한다.

주의: 위키 연지 설명은 마법 공격 증가21%이며 사용자 인게임 사진은 스킬 강화 단계22/24/26%를 제공한다. 사진의 해당 단계 수치를 우선하고 위키 숫자를 풀강으로 덮어쓰지 않는다. 펫의 강화·스킬 단계는 영웅의 6초월·5강 기준과 별개다. [2026-10-01 공식 공지](https://forum.netmarble.com/sena_rebirth/view/10/2080)의 네즈코도 소속 한정·스킬 단계별 효과가 있으므로 일괄적인 전체 아군 버프로 처리하면 안 된다.

## 이번 코드 반영

공통 성장 기준을 고정하고, 연희·쥬리의 강화된 계수·평타 대상 수와 연희 방어 무시40%를 적용했다. 효과 적중/저항 두 판정 및 상한 테스트를 추가했다. 전투 스케줄과 펫·반지 전체 효과는 조사 자료만 확보한 상태이며 아직 게임과 동일하게 동작한다고 표시하지 않는다.
