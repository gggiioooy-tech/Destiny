# 승패 예측 엔진과 검증 현황

목표는 실제 승패 일치율 90% 이상이지만 **아직 달성하지 못했다.** 반복 시드에서 90회 이겼다는 것과 실제 전투 90%를 맞힌다는 것은 별개다. 현재 모델은 실전 의사결정용 완성판으로 인증할 수 없다.

## 추가 구현

- Web Worker에서 100개 시드 반복 계산. 화면 입력을 막지 않으며 중지는 worker를 즉시 종료한다. 편성·스탯 변경, 전투 시작, 페이지 이탈도 계산을 취소한다.
- 공격/방어 승리와 행동 한도까지 결정되지 않은 경우를 별도로 표시한다. 미결을 임의 승리로 바꾸지 않고 공격 승률의 최저/최고 범위를 계산한다.
- 음수 치명타/약점/막기 수집 스탯을 보존하고 확률 판정에서 하한을 적용한다. 음수 공격력/HP 등은 거부한다.
- 부활 시 면역을 초기 면역으로 잘못 적용하던 파싱 수정, 풀스킬 부활 HP 강화, 불굴 피격 횟수와 절멸, 초기 보호막/축복, 선란 우위 일부, 회복의 재생 반영.
- 감전 추가 피해, 정의에 계수가 있는 화상/독 개인 턴 피해, 명시된 방어 무시 수치, 막기 감소, 기본적인 버프 해제 및 피해 전 효과 순서.
- 불사 상태에서 비치명 피해를 받았을 때 HP가 무조건 1로 떨어지는 오류와 방지된 치명 피해를 실제 HP 손실로 집계하던 오류 수정.

## 검증 방법

`node scripts/evaluate-battle-predictions.mjs PRIVATE_STATUS_JSON [PRIVATE_OUTPUT_JSON]`

입력은 로컬의 비공개 수집 기록이다. 시작 스탯과 실제 초기 예약만 읽는다. 실제 승패는 예측이 끝난 후 비교용으로만 사용하며 최종 HP, 피해, 관측된 후속 행동을 모델 입력으로 쓰지 않는다. sourceKey로 중복 제거한다. 스탯·예약 부족이나 현재 미지원 예약(각성 예약 포함)은 이유를 기록하고 제외한다. 기본값으로 빈 스탯을 채워 검증 표본을 부풀리지 않는다.

동일 날짜/길드에 치우친 상관 표본이다. 이는 회고 비교이며 독립 홀드아웃이 아니다. 판정 비율, 보류/제외 수, 실제 정답 수, 다수 클래스 기준선, Wilson 95% 구간을 함께 출력한다. 고신뢰 사례만 골라 전체 정확도라고 보고하지 않는다.

사용자 추가 다운로드 허용 후, 이미 관측된 정상 리플레이 경로 12개를 재다운로드·해석했다. 리디렉션을 거부하고 파일당 8MB 제한과 요청 간격을 적용했다. 게임 API 조회·경로 추측은 없다. 참가자/승패를 기존 기록과 대조했다. 원본, URL, 계정 식별자, 개인 수치는 `tmp/`에만 저장하며 배포하지 않는다.

## 현재 한계

초 단위 스킬 쿨타임과 전투 시간, 전체 고유 패시브/변신/각성 분기, 펫/장비의 특수효과, 엄호·방호·협공·반격, 중첩/해제의 완전한 순서가 미구현 또는 근사다. 지속 피해의 방어/피해 감소 적용과 적용 시점, 버프 해제 순서, 불굴과 피해 방지의 우선순위 등은 전체 실전 교차 검증이 더 필요하다. 공개 설명만으로 알 수 없는 부분은 검증 완료로 간주하지 않는다.

추가 12개 중 입력 조건을 충족한 10개 비교에서도 절반 정도만 일치하여 90%를 확인하지 못했다. 단일 테스트 성공이나 시드 반복 횟수를 정확도 근거로 사용하지 않는다. 상세 비교는 비공개 `tmp/battle-validation*.json`을 참조한다.
