# 반복 사용 흐름과 전투 규칙 보완

## 사용자 흐름

편성 / 전투 / 결과 분석으로 화면을 나눈다. 여섯 영웅은 작은 카드로 유지하고 선택한 영웅 하나의 스탯과 자료를 편집한다. 전투 시작 수치 입력을 전제로 하며 장비·펫·진형·상시 증가를 다시 가산하지 않는다.

- 스탯 표 붙여넣기: 단일 영웅 표 또는 이름 헤더가 있는 여러 영웅 표에서 선택한 영웅의 열을 가져온다. 천 단위 쉼표·소수·음수 효과 저항을 처리한다. 없는 항목은 보존하고 열을 식별할 수 없으면 적용하지 않는다.
- 명시적으로 저장한 조합만 해당 계정의 브라우저 저장소에 보관한다. 조합 파일은 128KB 이하이며 영웅·스탯·예약 스킬·시드만 허용한다. 미지의 속성은 버리고 수치·중복 영웅·버전을 검증한다.
- 빠른 계산과 자동 진행은 같은 엔진/시드를 사용한다. 이전 장면과 로그 선택은 이미 계산한 프레임을 보여주며 난수를 새로 뽑지 않는다. 종료는 이후 계산을 중단한다.
- 누적 피해, 남은 HP, HP 변화 그래프, 팀별 행동 로그를 제공한다. 결과를 검증된 실전 승률로 표현하지 않는다.

## 확인한 공개 근거

- [게임 전투 도움말 공개 데이터](https://7knightshub.com/data/tutorials/11.json): 게임 도움말의 한국어 텍스트를 제공하는 공개 팬 DB. 개인 턴·팀 스킬 턴·글로벌 쿨타임·예약 취소·회복 사용 조건·각성 게이지 설명을 확인했다. 공개 데이터의 지역/버전 차이는 여전히 확인 대상이다.
- [공식 2026-03-19 업데이트](https://forum.netmarble.com/sena_rebirth/view/10/965): 마비의 막기 0% 등 상태 효과와 공개 스킬 설명.
- [공식 2026-06-11 업데이트](https://forum.netmarble.com/sena_rebirth/view/10/1203): 생존·회복·부활 등 부가 효과 설명.
- [공식 2026-10-15 업데이트](https://forum.netmarble.com/sena_rebirth/view/10/2134): 최근 콜라보 안내 확인. 원문 빈 칸으로 확보된 각성 게이지는 다른 수치를 유추해 채우지 않는다.

반영한 도움말 규칙: 개인 턴 2회마다 팀 스킬 턴이 바뀜, 사용 불가 영웅 예약 취소, 예약 우선 각성 사용, 각성 개인 턴 종료 +15 / 일반 스킬 +45, 전투당 1회, 같은 팀의 다음 두 스킬 턴 동안 다른 각성기 제한, 사망 시 보유 게이지 10% 감소. 자동 회복과 예약 회복은 서로 다른 HP 조건을 적용한다. 단일 대상 다단 공격은 약점 판정을 공유하고, 빗나간 타격의 디버프를 배제한다.

추가로 원본 위키의 변신 하위 절이 일반 평타/1스/2스/각성기로 잘못 배정되던 파서를 수정했다. 코드별 중복을 제거하고 변신 분기는 미반영 상태로 명시한다. 각성 게이지는 `[각성 게이지]` 헤더의 명시된 숫자만 읽으며, 설명 중 감소량을 잘못 사용하는 것을 차단한다. 정의에만 있는 방어 감소 수치와 시전자 최대 HP 복합 계수, 일부 조건부 HP 피해 증가도 읽는다.

## 미완료 범위

초 단위 쿨타임 진행, 전체 고유 패시브·변신·각성기 부가 효과·협공·펫/장비 동작은 완성되지 않았다. 공식 자료를 찾았다는 것과 모든 영웅의 실전 결과를 검증했다는 것은 다르다. 현재는 조합/수치 비교와 장면 분석에 쓸 수 있는 참고 계산 도구이며, 실제 승패 예측 엔진 완성으로 보고하지 않는다. 추가 리플레이 서버 다운로드는 하지 않았다.
