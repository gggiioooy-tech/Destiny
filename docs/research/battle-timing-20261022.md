# 길드전 시간축 및 추가 행동

## 210초 및 종료 판정

사용자가 현재 길드전 제한 3분 30초를 확인했다. 개발자 노트 44편의 공식 작성자 게시물도 2분 30초 → 3분 30초 변경 방침을 설명한다: https://game.naver.com/lounge/sena_rebirth/board/detail/8168815

사용자 확인 기준: 양 팀이 생존한 시간 초과는 **팀 최대 HP 대비 잔여 HP 비율**로 판정한다. 양쪽이 불사 상태만 남으면 남은 불사 턴을 비교하고, 불사와 불굴만 각각 남으면 불사가 이긴다. 같은 HP 비율·불사 턴은 임의의 방어 승리로 바꾸지 않고 판정 보류한다. 여러 불사가 남으면 최장 잔여 턴을 비교하는 근사이며, 복잡한 혼합 상태 판정은 추가 검증이 필요하다. 사망한 영웅의 최대 HP도 팀 분모에 포함한다. 보호막은 HP 비율에 더하지 않는다.

다음 행동을 210초 안에 완료할 수 없으면 해당 행동 피해를 적용하지 않고 종료한다. 이는 타격별 발생 시점이 아닌 행동 완료 기준의 근사다. 시간 중간의 마지막 타격까지 정확히 재현한 것은 아니다. 180행동 안전 한도는 별도로 유지하며 이 경우는 시간 초과 승리가 아니라 미결이다.

## 영웅별 시간 자료

추가 다운로드한 기존 리플레이 12개를 로컬에서 다시 해석했다. 데이터 다운로드 없이 분석기를 재실행하여 패킷 소속과 ActionType, 시작/종료 시각을 보존했다. 23종 영웅에서 115개 시간 유형을 확보했다. 개인 정보나 결과·스탯은 카탈로그에 쓰지 않고 영웅/스킬/행동 유형별 표본 수·중앙값·범위만 기록한다.

`node scripts/extract-battle-timing.mjs [PRIVATE_REPLAY_REPORT_DIRECTORY]`

`StageTime/SkillEndTime`은 기록된 시계의 구간이며 순수 애니메이션 상수나 실제 네트워크 왕복 지연이라고 단정할 수 없다. 시간 미확보 행동은 다른 영웅의 같은 유형 중앙값을 사용하고 추정으로 표시한다. 행동 사이 공백 중앙값은 200ms다. 이 값에 반응 대기 등이 섞일 수 있어 서버 지연으로 부르지 않는다.

스킬 설명에서 확인된 초 단위 쿨타임은 사용 시작 시점 기준으로 재사용을 제한한다. 예약 스킬이 쿨타임이면 예약을 유지하고 해당 팀 스킬 차례를 넘긴다. 쿨타임 감소/증가/초기화의 전체 규칙과 기초 쿨타임 미확인 스킬은 여전히 누락이다.

## 우선 추가 행동

- 라드그리드: 적 공격에 의한 아군의 유효 피격 5회마다 별도 패시브 행동. 적 3명에 1,485 관통 고정 피해와 화상 35%/2턴. 고정 피해는 공격력·치명타·막기 등의 일반 피해 공식을 타지 않는다. 확보한 발동 구간은 744ms이며 행동 사이 공백은 별도다. 평타 개인 턴과 스킬 쿨타임을 추가로 소비하지 않는다.
- 루디: 피격된 주 행동당 38% 반격을 최대 1회 예약한다. 반격의 공개 피해 계수(공격력 50% + 방어력 60%)와 기절 35%/1턴을 적용한다. 관측된 ActionType 3 / 스킬 코드 4 구간은 1,000ms다. 전체 반격 우선순위, 전열 아군 연계 및 감쇄/링크 등은 아직 불완전하다.
- 하연: 본인 평타 후 엄호 63%로 행동 가능한 아군 한 명의 동일 대상 협공을 계산한다. 협공 영웅의 기본 공격 계수와 관측/추정 소요 시간을 사용한다. 관측된 ActionType 4 / 스킬 코드 1 사례(선란, 탄지로)로 구분했다. 대상 선정, 평타의 모든 부가 효과, 하연의 생명력 교환/전체 지원 규칙은 완전 재현되지 않았다. 즉시 처리되는 회복 패시브에 임의의 1초 동작을 붙이지 않는다.

추가 행동은 현재 주 행동 종료 후 순서대로 처리한다. 실제 다단 타격 중 끼어드는 정확한 인터럽트 순서와 다른 영웅의 반응 연쇄는 근사다. 64개 연쇄 안전 한도를 두고 로그에 한도 초과를 기록한다. 반격/협공 전체 및 서버 지연 구현 완료나 90% 정확도로 보고하지 않는다.
