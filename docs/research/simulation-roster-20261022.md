# 전체 영웅 선택과 전투 화면 확장

이 문서는 초기 확장 시점의 기록이다. 이후 각성 게이지와 반복 사용 기능을 보완한 최신 상태는 [실사용 흐름 보완](simulation-usability-20261022.md)을 참조한다.

2026-10-22 공개 자료 스냅샷: 176종. 공개 DB의 playable/isMaxStar 항목을 이름별로 묶고, 사용자가 지정한 한국판 나무위키 및 인게임 스킬 자료 61종을 우선 적용했다. 별도 희귀도·각성형을 근거 없이 혼합하지 않으며, 각성 자료가 있으면 해당 형태를 표시한다.

출처:

- [7Knights Hub 영웅 DB](https://7knightshub.com/heroes.html): 공개 이름·역할·초상화·스킬 수치. 한국 서버와 버전 차이가 있을 수 있음을 화면에 표시한다.
- 나무위키 각 문서 기여자: `src/lib/simulationRoster.json`의 영웅별 source. CC BY-NC-SA 2.0 KR. 기존 공개 자료 조사에서 확보한 한국판 스킬 구간을 사용한다.
- 각성 아일린은 사용자가 제공한 인게임 스킬 사진의 계수·타수·관통·감전 수치를 사용한다.
- [공식 10/1 업데이트](https://forum.netmarble.com/sena_rebirth/view/10/2080), [공식 3/19 업데이트](https://forum.netmarble.com/sena_rebirth/view/10/965): 공식 공개 스킬·부가 효과 안내를 확인했다. 모든 위키 수치와 전체 전투 엔진을 공식 검증했다는 의미는 아니다.

`scripts/import-simulation-roster.py`는 공개 팬 사이트만 조회하며 게임·리플레이 서버를 조회하지 않는다. 원본은 ignored tmp에 캐시하고 플레이어 스탯·전투 결과는 배포 데이터에 포함하지 않는다. 앱 실행 중 스킬 DB 요청은 하지 않으며 초상화만 공개 팬 사이트에서 불러온다. 초상화 오류 시 이름 아이콘으로 대체한다.

## 반영 범위

- 176종 선택·초성 검색·전설/각성 필터. 영웅별 스킬/패시브 자료·출처·부분 구현 표시.
- 저장 전투의 실제 양 팀 조합과 시작 스탯 불러오기. 다른 영웅 선택 시 이전 스탯을 초기화하며 같은 팀의 일치하는 스탯만 재사용한다.
- 공통 스킬 계산: 확인된 기본 계수/강화 계수·타수·대상 수·방어력 복합 계수·관통·방어 무시. 회복·보호막·부활·행동 제어·절멸·방어 감소 등의 인식 가능한 공통 효과.
- 연희·쥬리·윤건의 기존 개별 처리 유지. 미확인 스킬을 윤건 로직이나 임의 계수로 대체하지 않는다.
- 공격 이동·피격·피해 숫자·체력·보호막/상태 표식·스킬 배너·중단/속도 조절·누적 피해·행동 로그. 축소 화면 및 reduced-motion 지원.
- 4등급 전용 페이지/데이터 접근 유지. 추가 리플레이 다운로드 없음.

## 정확도 한계

전체 영웅을 배치할 수 있다는 의미이며, 모든 고유 패시브·각성기·협공·쿨타임·연속기·펫/장비를 완성했다는 뜻이 아니다. 조건을 해석하지 못한 효과는 부분 구현으로 표시하며 수치를 임의 생성하지 않는다. 상시 스탯 증가는 입력된 전투 시작 스탯에 포함된 것으로 취급한다. 최종 승패는 실험 결과로 표시한다. 원작의 3D 모델/모션을 사용하는 기능은 아니다.

검증은 모든 영웅의 유한한 HP·행동 처리, 알려진 수치 파싱, 회복 대상·저항 구분, 실제 조합 불러오기, 스탯 교체, 4등급 차단, UI 마크업 및 빌드를 포함한다. 전체 실전 전투 결과 일치를 증명하는 검증은 아직 아니다.
