# 영웅 정보창 입력에서 전투 시작 수치로 변환

기본 입력은 게임의 **사용할 장비 세팅을 선택한 영웅 정보창 수치**다. 장비·초월·+5 강화의 정보창 반영분을 다시 가산하지 않는다. 전투 시작 수치를 알고 있어야 입력할 수 있던 흐름을 교체했다. 기존 수집 기록과 v1 조합은 `battle` 입력 모드로 유지한다. 영웅 정보창 값으로 역산하여 가장하지 않는다.

## 입력·저장

양 팀의 펫, 강화(+0~+5), 스킬 단계(0~3), 잠재 네 줄(공격력/방어력/생명력), 진형의 후열 공격력/전열 방어력 보너스와 영웅별 전후열을 저장한다. 잠재 수치는 사용자가 펫 창에서 읽을 수 있는 값이다. 도감 기본 능력치는 자동 선택하며 사용자가 알 필요 없다. 176개 선택 영웅의 Lv.30 +5 기본 공격력·방어력·생명력을 공개 자료에서 확보했다.

새 v2 조합에는 `inputBasis`, `teamSettings`, 원래 입력한 `draft`를 저장한다. 계산된 수치가 원본 입력을 덮어쓰지 않는다. v1은 무조건 기존 전투 시작 수치로 읽는다. 계정별 명시적 로컬 저장·JSON 내보내기이며 자동 업로드하지 않는다. 시작 방식 전환 시 예시/원본 기록으로 초기화하여 시작 수치를 정보창 값으로 중복 계산하지 않는다.

## 산식과 중복

기초합 = 정보창 값 + 펫 성장 능력치 + 도감 기본값 × (같은 능력치 잠재 합 + 해당 열 진형 보너스) / 100.

시작 공격력·방어력·HP는 이 기초합에 확인된 시작 버프/디버프를 적용한다. 일반 영웅의 같은 유형·지속성 버프/디버프는 가장 큰 것, 펫 버프와 초기 고유 중첩은 별도 항으로 계산하는 현재 커뮤니티 모델이다. 모든 예외와 버프 종류 조합을 검증한 공식 일반 법칙은 아니다. 확률 스탯은 퍼센트포인트를 적용하고 치명/약점/막기 양의 증가 상한을 적용한 뒤 감소를 뺀다. 효과 저항 음수와 100% 이상 효과 적중은 보존한다.

선란의 초기 귀면 3중첩(공격력 +21%, 치명 피해 +30%), 시노부의 초기 독 축적, 탄지로의 내비치는 세계, 윤건 치명/약점, 쥬리 저항, 아일린의 물공/감전 확률/공격력 비례 효과 적중을 처리한다. 역할·전후열 조건과 상대 시작 디버프를 구분한다. 공격/방어/최대HP 비례 효과 적중/막기는 최종 시작 수치에서 계산한다. 물리/마법 취약과 감쇄는 방어자의 공격 타입이 아니라 실제 피해 소스 타입으로 고른다.

제오 공격력 버프 등 기간제 시작 효과는 별도 레이어로 기록하여 개인 턴/턴 감소/기본 버프 해제 시 해당 증가분만 제거한다. 연희의 기존 하드코딩 피해 버프를 다시 더하지 않는다. 스킬로 새로 얻는 복잡한 버프와 사망 시 모든 오라 갱신/중첩 재선정은 전체 구현되지 않았다.

## 자료

- 공개 캐릭터 DB: https://7knightshub.com/data/index.json 및 발견된 characters/{tid}.json 경로. 각성 영웅은 한국판 위키 Lv.30 +5 표를 우선한다.
- 펫 위키 참고: https://www.namu.moe/w/세븐나이츠%20리버스/펫
- 공개 펫 DB: https://7knightshub.com/data/pets-index.json 및 사이트 API 코드에 명시된 pets/{tid}.json. 43종 최고 성급 메타데이터·강화 단계 설명을 확보했다. 한국판 위키에 스킬 강화 단계가 빠진 경우 보충하며 지역/버전 차이는 확인 대상이다.
- 사용자 제공 이린/연지 단계와 제오 설명을 우선한다. 전설 펫 +5 성장 564/344/1895를 보존한다. 공개 reinforcement 배열이 +4에서 끝나는 경우 마지막 행을 +5로 오인하지 않는다.
- 진형 전열 방어·후열 공격 구분: https://ch.netmarble.com/Games/Detail?bbs_code=1004&post_seq=5834
- 각성 윤건 도감 기준: https://m.namu.moe/w/윤건(세븐나이츠%20리버스)/각성

펫 참고 44종 중 성장 수치를 확보한 30종을 선택 가능하게 한다. 자료가 없는 펫을 능력치 0으로 조용히 계산하지 않는다. 조건부/복합 타깃·비례 수치 누락 등은 계산 근거 안에 표시한다. 선택 가능·수치 유한 테스트는 실전 일치 검증이 아니다. 모든 영웅·펫·장비·진형의 모든 계산식이 검증됐다고 보고하지 않는다.


## 선택 범위 업데이트
펫은 루·이린·리첼·크리·파이크·델로·윈디·제브·유·요랑·연지·카람·제오·멜페로·네즈코 15종과 펫 없음만 선택한다. 전부 +5, 스킬 강화 3단계로 고정하며 이전 저장 파일의 낮은 강화 단계도 고정 기준으로 읽는다. 기존 멜패로/카마도 네즈코 명칭은 호환한다. 개별 조건부 효과의 검증 한계는 유지한다.

진형은 사용자 제공 값으로 기본(후열3/전열2, 공격14%/방어21%), 밸런스(2/3, 21%/14%), 공격(4/1, 10.5%/42%), 보호(1/4, 42%/10.5%) 중 선택한다. 실제 편성 3명의 열별 정원을 검증한다. 진형 변경 시 기존 열을 가능한 유지하며 초과한 인원만 이동한다. 기본 선택은 기본진형이다. 이전 수동 수치 저장은 정확히 일치하는 진형으로 변환하고 일치하지 않으면 기본진형으로 읽는다.

상단 실전 기록 선택/분석 JSON 열기와 해당 자동 조회를 제거했다. 직접 편성 및 사용자 조합 저장은 유지하며 4등급 권한 검사는 유지한다.


## 자리번호와 입력 흐름
진형별 전열 번호는 1~전열 정원, 후열 번호는 그 다음~5이다. 팀별 3명의 자리번호를 유일하게 보관하며, 점유된 자리로 이동하면 서로 교환한다. 자리에 따라 전열·후열 패시브와 진형 보너스를 적용한다. 진형 변경 시 열을 가능한 유지하고 새 번호를 배정한다. 기존 저장 파일은 전열·후열 정보에서 고유 자리번호를 복원한다. 조합 저장/공격·방어 교환에도 자리 설정이 함께 이동한다.
평타 큐는 속공 내림차순 후 자리번호 오름차순이며, 양 팀 간 속공·자리번호까지 같으면 기존 난수 판정을 유지한다. 전투 시작 수치 모드도 직접 선택한 자리번호를 큐에 전달한다.
편성 카드 바로 아래 자리 배치를 두고 펫/진형 설정, 선택한 영웅 스탯, 시작 스킬 순서로 입력한다. 펫 잠재와 계산된 수치/적용 내역은 접어서 볼 수 있다.
