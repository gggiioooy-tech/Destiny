# 전투 계산 실험판 진행 상태

고정 기준: 6초월·5강·풀스킬 강화. 현재 계산 엔진은 연희·쥬리·각성 윤건 3종만 지원한다.

이번 반영: 양 팀 예약 스킬, 팀 속공 합 선스킬, 스킬 사이 평타 2회, 평타 차례의 개인 지속 턴, 약점 피해·피해 증감·재생 입력, 무효화와 관통 구분, 보호막·축복·불사 만료·부활·생명력 전환. 회복의 재생 합산은 별도 검산 패널에서 두 가설을 비교하며 자동 전투 회복에 적용하지 않는다.

로컬에 이미 내려받은 전투의 첫 연희 2스킬 9타를 비교했다. 빗나감 80%, 윤건 축복 25%, 약점 추가 피해 35%를 가정하면 9타 모두 오차 2 이내다. 약점 추가 피해 35%는 장비를 독립 확인한 결과가 아니므로 전체 계산식이나 전투 결과가 검증됐다는 뜻은 아니다. 추가 리플레이 서버 요청은 하지 않았다.

미완료: 쿨타임·예약 이후 자동 선택·각성기·협공·전체 펫/장비 효과·동시 생존 효과 우선순위·고정/지속 피해의 보정 적용 범위·정확한 반올림 단계. 화면에 실험판과 누락 범위를 명시한다.

일반 수집기 확인: 로컬 status.json 37건에는 heroStats가 없고 status-red.json 36건에는 있다. 기존 DB는 상세 스탯을 별도 4등급 전용 테이블에 저장하고 일반 기록 재수집으로 삭제하지 않는다. 따라서 일반 수집 후에도 이전 빨간약 분석이 표시될 수 있다. 화면에 저장된 정보임을 표시하고, 일반 연결의 업로드 단계에서도 상세 스탯·예약 스킬을 제거한다. 기존 데이터를 삭제하거나 조회 권한을 확대하지 않는다.
